MiniCAD Windows x64 v0.3.7

Download the ZIP and extract all files. Run MiniCAD/MiniCAD.exe.
Bundled DWG reader: no ODA installation required.
Accelerates native DWG delete/explode with a reversible root-entity journal, incremental scene updates, direct prepared-view transfer and background edit preparation. Reduces cyclic GC overhead while reading DXF. First-time parsing and very large block expansion still take time. Other edits retain full-document history. Original files and vector printing are preserved.
Block decomposition: select block, click the block-decompose button, select internal geometry, then Delete.
Includes embedded MULTILEADER notes and on-drawing measurement labels.
No customer drawings are included.
Windows WebView2 Runtime is required.
