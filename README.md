MiniCAD Windows x64 v0.3.9

Download the ZIP and extract all files. Run MiniCAD/MiniCAD.exe.
Bundled DWG reader: no ODA installation required.
Uses a compositor transform for continuous navigation and a separate cursor overlay, eliminating per-frame canvas copies. Reads reachable DWG block bodies for a transient view while preserving the full original DXF cache. Full editing data is loaded on the first modification rather than concurrently with viewing. First editing can therefore take extra preparation time. Keeps incremental DWG delete/explode. Original files, exact measurement coordinates and vector printing are preserved.
Block decomposition: select block, click the block-decompose button, select internal geometry, then Delete.
Includes embedded MULTILEADER notes and on-drawing measurement labels.
No customer drawings are included.
Windows WebView2 Runtime is required.
