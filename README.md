MiniCAD Windows x64 v0.3.10

Download the ZIP and extract all files. Run MiniCAD/MiniCAD.exe.
Bundled DWG reader: no ODA installation required.
Adds direct camera updates without per-frame full React commits; performance-first rendering is on by default for integrated graphics and 8GB systems. Reduces raster buffers, snap bounds duplication, spatial-index sorting and JSON copies. Uses bundled native JSON encoding with strict finite-coordinate validation. Uncheck Performance First for high-DPI sharpness. Drawing coordinates, snapping and vector printing stay unchanged. First DWG interpretation and first edit preparation still take time. Original files are preserved.
Block decomposition: select block, click the block-decompose button, select internal geometry, then Delete.
Includes embedded MULTILEADER notes and on-drawing measurement labels.
No customer drawings are included.
Windows WebView2 Runtime is required.
