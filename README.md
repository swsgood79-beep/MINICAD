MiniCAD Windows x64 v0.3.12

Download the ZIP and extract all files. Run MiniCAD/MiniCAD.exe.
Bundled DWG reader: no ODA installation required.
Window printing now outputs only the selected drawing rectangle: no application filename, unit summary or warning report. Automatically fits A4 landscape or portrait, preserves aspect ratio and vector annotations, and suppresses default Chromium date/title/URL headers through zero page margins. Hardware printer margins and custom header policies remain device-specific. Full drawing report printing is retained.
Block decomposition: select block, click the block-decompose button, select internal geometry, then Delete.
Includes embedded MULTILEADER notes and on-drawing measurement labels.
No customer drawings are included.
Windows WebView2 Runtime is required.
