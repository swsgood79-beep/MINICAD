MiniCAD Windows x64 v0.3.8

Download the ZIP and extract all files. Run MiniCAD/MiniCAD.exe.
Bundled DWG reader: no ODA installation required.
Keeps the current raster during continuous pan/zoom across cache edges and large scale changes; batches accumulated wheel input per frame; refines detail in cancellable slices after idle. Caps high-DPI raster memory. The preview can temporarily soften or show a blank edge; full detail returns after refinement. Keeps incremental DWG delete/explode from v0.3.7. Original files and vector printing are preserved.
Block decomposition: select block, click the block-decompose button, select internal geometry, then Delete.
Includes embedded MULTILEADER notes and on-drawing measurement labels.
No customer drawings are included.
Windows WebView2 Runtime is required.
